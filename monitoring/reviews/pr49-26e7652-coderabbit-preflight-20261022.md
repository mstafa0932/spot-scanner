# PR49 — نتيجة شروط تشغيل CodeRabbit CLI

**النتيجة: توقف قبل تشغيل المثبّت أو CLI وقبل إرسال المصدر؛ بيئة الجلسة لا تتيح فرض العزل المطلوب.** موافقة المستخدم على المراجعة المجانية محفوظة ومشروطة بضوابطه؛ لا نطلب استثناءً منها.

- الرأس ما زال `26e765239ef3a445565ce3291c0a28fa7bcff683`، وPR مفتوح وغير مدمج.
- CI `39716978157` ما زال ناجحًا على الرأس نفسه. لم نكرر الاختبارات أو نغيّر الكود.
- التكلفة الفعلية صفر دولار؛ لم يبدأ تسجيل دخول أو اشتراك أو طلب مراجعة.

## العائق المثبت

اختبارات العزل المحلية لم تشغّل كود البوت أو أي برنامج من CodeRabbit:

| الفحص | النتيجة |
|---|---|
| bubblewrap مع عزل namespaces | رفض إنشاء NETLINK_ROUTE، ثم رفض إنشاء namespace في محاولة مستقلة |
| user namespace / uid map | Operation not permitted |
| Landlock | ENOSYS / Function not implemented |
| Linux capabilities | جميعها صفر، مع NoNewPrivs=1 |
| Docker/Podman أو runtime بديل متاح | لا توجد الأدوات أو socket صالح ضمن القدرات المفحوصة |

إنشاء مجلد مؤقت أو بيئة Python لا يفرض منع الوصول إلى ملفات الجلسة أو ضبط الاتصال الخارجي. لذلك لم يُستبدل العزل بمجلد عادي، ولم يُشغّل CLI خارج القيد المطلوب. هذه قيود تنفيذ مثبتة، وليست نقصًا في تفويض المستخدم أو خطأً في PR.

## ما أُنجز بأمان في سلسلة التثبيت

حُمّل نص المثبّت الرسمي فقط عبر HTTPS من:
https://cli.coderabbit.ai/install.sh

فُحص النص دون تشغيله. يحدد الإصدار Linux المستقر `0.9.1`، ويتحقق من توقيع SHA256SUMS قبل الاستخراج. لكنه يستدعي `coderabbit doctor` في نهاية التثبيت، لذلك لم ننفذ المثبّت خارج العزل المطلوب.

حُمّلت ملفات الإصدار الصغيرة SHA256SUMS وSHA256SUMS.sig وVERSION من المسار الرسمي الثابت:
https://cli.coderabbit.ai/releases/0.9.1/

نجح التحقق باستخدام OpenSSL من توقيع البيان بالمفتاح المنشور داخل المثبّت الرسمي، ومن قيمة VERSION وبصمتها. بصمة نص المثبّت:
`a971b226f9f0d94e948372a24ce1eb51f244093542e0597e4d21cfd520ab0cd8`.

**لم يُحمّل ملف البرنامج الثنائي أو يُنفذ، ولم يكتمل التحقق من سلامة الحزمة الثنائية.** التحقق الناجح هنا يخص بيان الإصدار وتوقيعه، وليس شهادة بفحص كل محتويات البرنامج أو سلوكه.

## نطاق البيانات والاعتماد

لم تُرسل الشفرة أو الأسرار أو env أو بيانات الاعتماد أو الحالة أو سجلات الإنتاج إلى خدمة المراجعة. لم تُجهز حزمة المصدر للإرسال، ولم نرصد طلب مراجعة فعليًا؛ لذلك **شرط التحقق من الحمولة الفعلية ما زال غير منجز**، ولم نفترض أن CLI يرسل الفرق فقط.

لا توجد مراجعة خارجية جديدة أو نتيجة مانعة/غير مانعة صادرة عن CodeRabbit. تبقى نتائج CI والفحوص السابقة محفوظة، وبوابة الاستقلال غير مكتملة. لا حساب مراجع وهمي ولا اعتماد ذاتي أو APPROVED.

## نقطة الاستئناف

يلزم نقل مرحلة التنفيذ إلى runner/VM مؤقت يدعم عزل الملفات والعمليات، وحصر/رصد الاتصال الخارجي، دون بيانات اعتماد إنتاج أو صلاحيات كتابة GitHub. بعدها فقط:

1. التحقق من الرأس الثابت والشروط نفسها.
2. استكمال تحقق الحزمة الثنائية قبل التنفيذ.
3. تحديد وفحص الحد الأدنى من المدخلات واستبعاد الأسرار والحالة والسجلات والبيانات الشخصية وبيانات Git غير اللازمة.
4. التحقق من نطاق الحمولة الفعلي، لا الاكتفاء بوصف الوثائق أو افتراض diff فقط.
5. تأكيد مجانية الطلب وعدم تفعيل دفع أو رصيد مدفوع، ثم تنفيذ المراجعة وحفظ خرج الخدمة إن سمحت جميع الشروط.

هذه المتطلبات لا تفوض إنشاء بنية جديدة مدفوعة أو تعديل Workflow أو ربط GitHub App. أي مسار إضافي يحتاج موافقة مناسبة قبل تنفيذه. لا يُطلب تخفيف ضوابط المستخدم.
