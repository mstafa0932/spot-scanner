## الخيار المحدد وسبب اختياره

**CodeRabbit CLI في وضع المراجعة المحلية، من CodeRabbit Inc.** هو أداة خدمة خارجية مستقلة عن منفذ الإصلاح. GitHub يوثّق ناشر CodeRabbit في Marketplace؛ هذا إثبات هوية الناشر، وليس شهادة بجودة كل نتيجة. المخرجات مراجعة AI آلية، وليست مراجعة بشرية أو GitHub APPROVED.

تدعم الوثائق تحليل فروق Git المثبتة وإخراج نتائج منظمة، مع سلوك Free محدود للمستودعات التي لم يُثبّت تطبيق CodeRabbit عليها. لا نعتمد وضع remote الذي يشترط تثبيت التطبيق. الخطة مجانية ضمن الحدود المعلنة؛ لا بطاقة أو شراء مطلوب لخطة Free. لن يُستخدم رصيد مدفوع، وأي مطالبة برسوم توقف التنفيذ.

درست أيضًا تطبيقَي CodeRabbit وSourcery. كلاهما يطلب كتابة الكود وWorkflow؛ Sourcery يطلب كذلك كتابة Actions. لذلك لا أوصي بربط أي منهما بالإنتاج لهذه المهمة. قابلية اختيار مستودع واحد لا تزيل قدرة الكتابة داخله.

## الصلاحيات والخصوصية

المطلوب في هذا الاقتراح:

- تثبيت البرنامج من المصدر الرسمي في مساحة المراجعة، بعد فحص طريقة التثبيت وتسجيل الإصدار والبصمة.
- تسجيل دخول المستخدم الفعلي إلى CodeRabbit. تُفحص شاشة الموافقة؛ أي طلب لتثبيت GitHub App أو كتابة مستودع أو إدارة أو أسرار خارج هذا الاقتراح يوقف العمل.
- قراءة نسخة مقيدة للمصدر المنشور وفرق PR وإرسالها إلى خوادم CodeRabbit ومزودي المعالجة وفق سياسة الخدمة.
- عدم تزويد الخدمة بمفاتيح GitHub أو Telegram أو Render أو ملفات env أو الحالة أو الأرشيف. تشغيل المراجعة ببيئة خالية من بيانات اعتماد الإنتاج.
- حفظ النتائج الخام والسياق والبصمات في فرع المراقبة بعد المراجعة. لا تطبيق تلقائي لاقتراحات ولا تغييرات في PR أو main.

**تحفظ خصوصية جوهري:** سياسة CodeRabbit تستثني OSS من تعهد عدم استخدام البيانات في التدريب، وتذكر استخدام OSS لتدريب أنظمتها. المستودع عام؛ لذلك لا أضمن عدم استعمال المصدر المرسل في التدريب. لا يتضمن الاقتراح أي ضمان احتفاظ صفري أو ضمان عدم تدريب. يلزم قبول هذه النقطة صراحة ضمن الموافقة.

## تنفيذ محدد بعد الموافقة فقط

1. التحقق مجددًا من الرأس وCI؛ أي تغير يوقف اعتماد النتائج القديمة.
2. تجهيز نسخة مراجعة دون بيانات اعتماد أو ملفات حالة إنتاج، وتثبيت ارتباط المصدر بالرأس والبصمات. شجرة الرأس `b16d4469e75f101f84f59264eaed9b71820b5ff5`؛ بصمة scanner.py `5e55deeae9bb077fe1e8d0ca63414f739321410e`؛ بصمة الاختبار `514586ecc4cfe978ffb1bf7fcde664ddfea8dbe8`.
3. التحقق من هوية اتصال CodeRabbit والخطة والحصة ومن أن التكلفة صفر. لا ترقية أو تفعيل pay-as-you-go.
4. استعمال مراجعة Git محلية عند الرأس المحدد، بمقارنة قاعدة PR `19baf43a072e6702373517106a3561514cd2ea85`؛ الملفان المتغيران هما scanner.py والاختبار فقط. إرفاق [تعليمات المراجع](pr49-26e7652-external-review-instructions.md) والأدلة العامة المحفوظة. استخدام المراجعة الأعمق إن كانت ضمن الاستحقاق المجاني المتاح، دون شراء.
5. حفظ الخرج الخام وإصدار الأداة ووقت الطلب وبصمات المدخلات وأي معرف جلسة توفره الخدمة. لا ننسب إلى الخدمة SHA أو موافقة لم يظهر في خرجها؛ إن كان ربط SHA من سجل التنفيذ فقط، يُذكر ذلك بوضوح.
6. التحقق من تغطية الملفين والموضوعات السبعة. إن غاب سياق كافٍ أو تخطت الخدمة ملفات أو اقتصرت على فحص سطحي، لا نعتبر ذلك اكتمالًا للمراجعة المطلوبة.
7. أي خطأ مثبت يوقف الاعتماد ويُرفع للمستخدم مع خطة واختبار مقترحين دون تعديل. التقرير الخالي من اعتراضات لا يُحوّل تلقائيًا إلى APPROVED أو إذن دمج.

## حالة الاعتماد ونقطة التوقف

لم يُثبت خلل جديد في PR ضمن هذه المهمة؛ لم تنفذ الخدمة مراجعة بعد، ولذلك لا توجد نتيجة مستقلة جديدة أو حكم خلو من الموانع. نتائج Bandit السابقة تظل صفر نتائج جديدة مع LOW قديمين، وليست موافقة مستقلة.

يبقى شرط الاستقلال/التقرير الخارجي قيد الانتظار، وتبقى بوابة GitHub الرسمية غير مكتملة. هذا المسار لا يعد بموافقة بشرية ولا يتجاوز شروط التسليم. الموافقة المطلوبة الآن تخص مراجعة مجانية محدودة البيانات؛ الدمج قرار منفصل بعد فحص النتائج.
